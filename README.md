# Sammprada Hospital

A responsive Sammprada Hospital homepage built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and GSAP. It uses the hospital's navy-and-blue palette, nested navigation, hospital imagery, doctor profiles, specialties, health packages, news, FAQs, and footer details.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Images and links point to the official Sammprada Hospital website.
